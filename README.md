# 无聊英语 · 精读训练

这是“无聊英语”双入口产品。阅读训练与考研精读库为当前主流程；单词库、中考库与高考库保持不变。

## 已完成

- 双入口首页：阅读训练 / 单词背诵。
- 单词栏目保留原“考研词汇筛查器”：登录、词库、筛查、学习、导出、混淆词与独立背词训练；`KaoyanVocabDB` 与 `KaoyanVocabMemorizeDB` 数据结构不变。
- 考研官方库：2007–2023 年共 68 篇英语（一）精读（17 年 × Text 1–4）。
- 精读流程引擎（A）：导读 → 审题 → 限时读文 → 初做 → 逐段精读 → 重做 → 复读压缩，共 7 个阶段；每篇文章独立保存流程与限时计时，完成后只写入 `reading-activity` 作为本机段位计分事实源。
- 逐句笔译工作台（B）：按段按句笔译、AI 批改、订正、已掌握 / 需复盘；“mastered / needs_review” 只由 B 保存，其余模块只读。
- 阅读题证据链（C）：first / redo 答案与原文证据（多句或全局证据）、证据跳句、错题对比；答案与证据分别隔离保存。
- 次日复读系统（D）：完成精读后自动生成次日任务，按盲读 → 困难句 → 错题重做 → 核对推进；困难句复查（3 天后）独立成任务。复读完成不会改写 A 的流程状态，也不会重复计分。
- 文章学习结果 + 今日任务（E）：Article Learning Summary 与 Today Tasks 只读聚合 A–D、陌生词与 AI 学习记录；首页任务按需加载，不扫描整篇正文。
- 本地 PDF 上传：自动保存到“自定义库”并直接生成连续精读版；双通道本地识别（PDF 文字层 + 离线 Tesseract OCR），不上传资料、不调用云端 AI。
- 自动识别仔细阅读 Text 1–4、原文段落、原题号、英文题干和 `[A]`–`[D]` 选项；无题资料按纯文本精读版继续，不假设永远有 5 道题或官方答案。
- 悬浮习题窗与第一次做题实时同步，位置与模式保存在本机；限时读文与复读提取阶段会按规则隐藏/恢复。
- 画笔、圈选橡皮、撤销、清空本页、电容笔长按切换橡皮；笔迹按资料保存在本机，手指滚动与 M-Pencil 书写分离。
- 导出成品 PDF 只包含六模块学习内容（导读、干净原文、第一次做题、逐句笔译与订正、正式重做、全文压缩与第二天复读），交互控件不会进入成品。

## 数据与兼容

- 所有学习记录只保存在当前设备浏览器：流程、笔译、证据、复读任务、答案、笔迹、陌生词与 PDF 均按账号隔离。
- 旧 `localStorage` / IndexedDB 记录仍可读取；新字段均为增量，采用“读取时归一化”，不做批量迁移。
- 线上版与电脑本地版网址不同，学习记录分别保存在各自浏览器中，不会自动同步。

## 离线识别说明

当前版本随应用打包 PDF.js、Tesseract OCR、英文识别模型和 WebAssembly 核心，全程可离线运行。扫描页首次转换比文字型 PDF 慢，界面显示当前页进度；识别结果与原 PDF 都保存在当前浏览器中。OCR 准确度受扫描清晰度、倾斜和污渍影响，可用“查看原 PDF”随时对照。

验收样本：`2006年真题及答案速查.pdf`（16 页扫描件）已实测识别为 4 篇仔细阅读、22 段原文、96 个逐句单元和 20 道选择题。

## Git 版本回退

此项目使用 Git 保存每个稳定改动。开始或结束一项功能前先运行 `git status` 查看改动；确认功能可用后，执行 `git add <文件>` 和 `git commit -m "说明"` 留下一个可回退点。

撤销尚未提交的单个文件可用 `git restore <文件>`。需要回到较早版本时，先创建保护分支 `git branch backup-before-restore`，再检查或恢复旧提交，避免直接改写已有历史。
