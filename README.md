## 读过之后，还能留下什么？

一篇文章的学习结果，不止是一个分数。无聊英语围绕学习过程组织内容：先独立读和做题，再逐句理解、寻找证据、订正表达，最后通过复读和复习检验自己是否掌握。

文章中的陌生词、困难句、错题、笔译和手写批注可以留在各自的学习记录中，方便继续学习与回顾。

## 可以用它做什么？

| 学习模块 | 主要能力 | 适合的学习任务 |
| :--- | :--- | :--- |
| **真题精读** | 分阶段阅读、限时读文、首次作答、逐句笔译、答案证据与正式重做 | 把“选对答案”推进到“说清为什么选” |
| **完形训练** | 完形资料库、作答、句子学习、订正与学习档案 | 在上下文中理解词义、搭配和文章逻辑 |
| **词汇学习** | 词库管理、筛查、背诵、复习、混淆词与词库导入导出 | 先找出不会的词，再持续记忆和复习 |
| **长难句** | 句子训练、翻译、AI 辅助与独立训练记录 | 集中处理影响理解的复杂句子 |
| **写作训练** | 范文阅读、英译中、回译、对照诊断、骨架提炼、重构、独立写作与评分改写 | 把读懂的表达转化为自己的输出 |
| **复读与任务** | 次日复读、困难句回查、今日任务与学习结果汇总 | 用后续复习检查是否真正记住 |

### 阅读，有明确的训练路径

内置 **2007–2023 年考研英语（一）Reading Part A，17 年、68 篇文章**，也支持导入自己的 PDF 资料。

```text
导读 → 审题 → 限时读文 → 初做 → 逐段精读 → 重做 → 复读压缩
```

- **先独立完成。** 保留第一次作答，便于之后对照自己的判断。
- **回到原文找依据。** 记录题目对应的原文证据，并跳转到相关句子。
- **逐句完成笔译与订正。** 标记掌握情况，把需要复盘的句子留下来。
- **隔天再检验。** 通过盲读、困难句复查和错题重做检查学习结果。
- **导出学习成果。** 将阅读、作答、笔译与订正等内容整理为 PDF。

### 手写与资料，留在学习现场

阅读工作台提供画笔、圈选橡皮、撤销等批注工具，笔迹随对应资料保存。可以在原文旁圈画，也可以结合键盘输入完成笔译与写作。

自定义 PDF 支持文字层提取和本地 OCR：有题目的资料按识别结果进入训练，没有题目的文章也可以继续精读。扫描件识别受清晰度、倾斜和版式影响，学习时可以对照原 PDF 核查。

### AI，参与具体的学习任务

AI 可用于翻译批改、句子理解、写作诊断等任务。先在应用的 **AI API 设置** 中配置服务、API Key 和模型，再使用相应功能。

AI 功能需要网络连接，可能产生所选服务的 API 费用；相关文本或图片会按功能需要发送给配置的服务。批改与评分用于辅助学习，仍应结合原文、参考答案和自己的判断核对。

### 三种可以直接开始的用法

1. **精读一篇真题。** 进入阅读库，选定年份和文章，先限时阅读并完成初做，再逐句笔译、核查原文证据，最后重做和复读。
2. **把不会的词集中学。** 在词库中筛查陌生词，进入背诵训练，再从复习入口回顾。阅读时也可以记录遇到的陌生词。
3. **把范文变成自己的表达。** 进入写作训练，从范文阅读和回译开始，对照差异、提炼结构，再尝试独立写作与修改。

## 从源码运行

准备 Node.js 与 pnpm，在终端依次执行：

```powershell
git clone https://github.com/liu2678294813-cpu/wuliao-english-private.git
cd wuliao-english-private
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

Windows 也可以在构建后双击 `启动无聊英语.cmd`。本地使用地址固定为：

```text
http://127.0.0.1:4173
```

开发调试：

```powershell
pnpm dev
```

开发服务器的地址可能与正式本地运行地址不同，学习记录按访问来源分别保存。请用测试账号调试。
