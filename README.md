# 无聊英语 · 精读训练初版

这是“无聊英语”双入口产品原型。本轮只新增阅读训练和考研精读库，单词库、中考库与高考库保持不变。

## 已完成

- 双入口首页：阅读训练 / 单词背诵。
- 单词栏目已合并原“考研词汇筛查器”：保留登录、词库、筛查、学习、导出、混淆词与独立背词训练。
- 原 `KaoyanVocabDB` 与 `KaoyanVocabMemorizeDB` 数据结构保持不变；“记录 n/3”、第三次遮挡、滚动位置与清除功能均保留。
- 考研官方库：2007–2023 年，共 66 份英语（一）精读 PDF。
- 六阶段精读流程：题干预览、干净原文、第一次作答、逐段笔译订正、正式重做、第二天复读。
- 本地 PDF 上传：自动保存到浏览器的“自定义库”，并在设备上直接生成连续精读版。
- 双通道本地识别：优先读取 PDF 文字层；扫描版 PDF 自动切换为离线 Tesseract OCR，不上传资料、不调用云端 AI。
- 自动识别仔细阅读的 Text 1–4、原文段落、原题号、英文题干和 `[A]`–`[D]` 选项。
- 自动套用精读模板：文件标题首页、全部题干第一读、干净原文、第一次做题、逐句笔译与订正、正式重做、复读压缩。
- 逐句笔译区按段落和句子连续向下排列，并依据英文句长生成对应数量的书写横线。
- 每段完成逐句笔译后重新按句列出本段英文原文，再进入“段落中心思想”，便于逐句核对。
- 自定义资料与考研库共用同一套结构化精读版式、阅读器导航、笔记工具和悬浮习题窗；第一次做题与题窗中的选择会实时同步。
- 考研库悬浮习题窗支持逐项点击选择并保存，重新打开资料后仍保留答案。
- 考研库 PDF 中的静态题目会自动转换为与自定义资料一致的可点击题卡。
- 画笔、圈选橡皮、撤销、清空本页；用橡皮圈住笔迹并松手即可删除圈内内容，笔迹按资料保存在本机。
- 电容笔长按约 0.6 秒，在画笔与橡皮擦之间切换。
- 页码进度与答题选择保存在本机。
- 官方题库改为先完整读取本地 PDF 再交给 PDF.js 渲染，减少旧版按 URL 分段加载时偶发的打不开问题。

## 启动

双击 `启动无聊英语.cmd`。浏览器会自动打开 `http://127.0.0.1:4173`。合并后的阅读与单词模块共用原单词软件地址，因此原有本地词库和背词记录可以继续使用。

手机与平板正式版：<https://wuliao-english-mobile.netlify.app>

线上版与电脑本地版使用不同的网址来源，因此学习记录分别保存在各自浏览器中，不会自动互相同步。

如需重新构建：

```powershell
pnpm install
pnpm build
```

## 离线识别说明

当前版本随应用打包 PDF.js、Tesseract OCR、英文识别模型和 WebAssembly 核心，全程可离线运行。扫描页首次转换会比文字型 PDF 慢，界面会显示当前页进度；识别结果与原 PDF 都保存在当前浏览器中。OCR 准确度仍会受扫描清晰度、倾斜和污渍影响，可用“查看原 PDF”随时对照。

验收样本：`2006年真题及答案速查.pdf`（16 页扫描件）已实测识别为 4 篇仔细阅读、22 段原文、96 个逐句单元和 20 道选择题。

## Git 版本回退

此项目使用 Git 保存每个稳定改动。开始或结束一项功能前先运行 `git status` 查看改动；确认功能可用后，执行 `git add <文件>` 和 `git commit -m "说明"` 留下一个可回退点。

撤销尚未提交的单个文件可用 `git restore <文件>`。需要回到较早版本时，先创建保护分支 `git branch backup-before-restore`，再检查或恢复旧提交，避免直接改写已有历史。
