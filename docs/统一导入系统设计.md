## 用户流程与责任

首页单选目标 → 批量选择 → 格式校验 → 完整本地提取（必要页面 OCR）→ 目标结构适配 → 去重、校验 → 集中编辑 → 缺失答案处理 → 确认导入 → 事务完成并回读 → 资料库训练。

文件状态 selected/validating/extracting/structuring/review_required/ready/committing/completed；异常 failed/cancelled/duplicate/unsupported。批次持久化候选与修正，恢复不自动调用 AI。每个文件独立失败，逐文件逐页处理，50 文件/100MiB 单文件/500MiB 批次。

import 子目录承载 contracts、extractor、parsers、repository、controller、answers、ai 和 UI。复用 PDF.js、OCR 生命周期、deepReadingParser、clozeParser、WritingRepository、Text AI Provider。App 只接入口。新 store 只存导入、来源、作文材料、答案/解析/评分版本，不存另一套进度。

## 契约与兼容

来源身份 username+文件 SHA；材料身份 username+target+文件内条目；内容指纹用于跨文件去重。候选创建时冻结条目/题目身份，标题及答案变化不改变 ID。阅读/完形写 custom-pdfs 的原模型，只含单条目标内容；file 为共享来源的运行时解引用，备份保留来源记录。旧记录/ID 原样读取。

作文材料保存 promptText/directions/taskType/year/referenceEssay/assets/source，年份未知 null。待完善材料可保存但不可创建 Session。完整资料经现有 commands.startWritingSession，manual_import 冻结题面/范文；官方关联只允许精确指纹身份，不靠年份猜测。

答案与解析分 store。答案保存 materialId/questionId/number/value/source/mappingStatus/reviewStatus/revision/sourceLocation/provenance。source_document/ai_generated/manual；用户修改 AI 结果保留 ai_generated。待核对答案可随正文保存，不参与批改，不作为缺失题请求 AI。原文件已匹配答案优先。

有效答案映射要求章节、题号唯一、选项有效；顺序推测不确认。只有已核验内置官方依据进入正式正确率，其余参考统计独立。统计显示覆盖率，未知答案不计分母。订正自动追加评分版本，原作答、计时、旧成绩不改变，解析单独变化不重评。

JSON v1：{format:"wuliao-material-import",version:1,items:[{target,title,content,answers?,explanations?}]}；同时适配现有 passages/clozes 和严格验证的私有作文格式。资料字段不能自行授予官方身份。

## AI 边界与恢复

未授权请求数必须为 0。缺失题仅提供 AI生成/手动录入/暂不添加；AI 点击后展示上下文，确认发送，结构化输出校验后仍只是候选，再确认保存。可编辑、删除、主动重生成；不自动重试、不静默覆盖。失败保留正文。缓存包含账号/模型/提示版本/输入指纹。

账号在批次、事务和返回结果处验证，账号切换取消任务。材料、答案、解析、回执事务写入并回读；恢复按回执跳过成功项。正式来源、素材、作文、答案、待核对记录、评分修订进备份；缓存/未提交批次排除。恢复验证关联完整性。

## 验收矩阵
