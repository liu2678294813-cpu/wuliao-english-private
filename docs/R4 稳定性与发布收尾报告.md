## 二、R4 发现

### 已确认并修复的 Bug

1. `AiFloatWindow` 的空请求上下文字段会覆盖父级 `resourceId/passageId`，导致正常 AI 结果被 stale guard 丢弃。
2. `aiContext` 内联对象导致每次父组件重渲染都触发 cleanup，误 abort in-flight 请求。
3. Vocabulary adapter 将父端新协议转为 CustomEvent，但旧业务脚本只监听 `message`，导致父向子导航/设置/返回消息不通。
4. `app-polish.js` 引用了未定义的 `EMBEDDED_INITIAL_HISTORY_LENGTH`。
5. 全新 `wuliao-english` IndexedDB 的 `custom-pdfs` store 漏建 `fingerprint` index。
6. `storage.js` 在 request success 时提前 resolve，没有等待 transaction complete，也没有完整处理 abort/error。
7. 导入编辑器卸载后，队列可能永久等待未 resolve 的 editor promise。
8. Android WebView 下无 BOM UTF-8 CSV 被 SheetJS array 模式错误解码，合法中文释义被判无效。

### 稳定性风险

- PDF Reader 原路径补充了 AbortSignal、加载失败重试和卸载销毁。
- Cloze 加载增加 watchdog 和重试；长期档案加载增加错误态。
- AI Key 测试增加 10 秒 timeout；未知词 AI 释义链增加卸载保护。
- 词汇 PDF 导入增加 timeout、page cleanup、PDF destroy；CSV 使用 string 模式。
- Planner 失败增加可执行重试；Settings PIN timer 增加卸载清理。
- 核心页面增加局部 ErrorBoundary，可返回首页；保留全局 reload fallback。

## 四、Async Recovery

| 任务 | timeout/watchdog | cancel/abort | error | retry |
|---|---|---|---|---|
| PDF | PDF.js/OCR 既有 timeout；Reader 加载由生命周期终止 | 支持 AbortSignal、卸载 destroy | 有错误态 | Reader/Import 可重试 |
| OCR | worker init 60s、page 120s | AbortSignal、worker terminate | `PdfImportError` 分类 | 导入编辑器重新解析 |
| AI | 普通请求 90s；Key test 10s | AbortSignal、context switch、组件卸载 | 网络/服务端/解析错误 | 现有重发/重试入口 |
| Vocabulary iframe | 10s load watchdog | reload/retry、Bridge reset | iframe failed/error state | 重新加载 |
| Vocabulary import | PDF/file/page 60s watchdog | 页面退出可终止业务等待 | status error | 重新识别 |
| Custom import queue | 解析取消与组件卸载 guard | editor promise resolve、AbortSignal | failed/cancelled 状态 | 资料卡重试 |
| Backup export/restore | UI finally 保证不永久 loading | restore 为可终止的分段操作，跨存储边界明确 | 错误逐项报告 | 可重新 merge |

## 五、Backup / Restore

- Format：`wuliao-backup`
- Version：`1`
- Manifest 字段：`format`、`version`、`createdAt`、`appVersion`、`schemaDescription`、`accounts`、`sections`、`attachments`、`checksum`
- included：当前账号作用域 localStorage 学习数据、reading/cloze/translation/evidence/review/Planner、AI learning records/history、unknown words、词库 DB 用户记录、custom PDF 原始 Blob 和 analysis
- excluded：API Key、PBKDF2 passwordHash/salt/iterations、`KaoyanVocabDB.users`、AI cache、PDF parse cache、telemetry、developer mode、LearningStateSnapshot、当前登录指针、sessionStorage
- Secret handling：普通备份中 API Key 和认证凭据永不导出；恢复也不会创建或覆盖认证凭据
- Restore strategy：只支持同用户名安全 `merge`；预览 → 账号校验 → 冲突检测 → 写入 → 抽样验证 → journal
- Account isolation：A 的 backup 恢复到 B 直接拒绝；不会隐式重命名或改写账号作用域
- Idempotency：同一 backup 连续恢复第二次只跳过已有记录，不重复 review task、learning record、词汇或 custom PDF
- Transaction boundary：localStorage 与 IndexedDB 不共享单一事务；失败会返回 partial failure，不显示成功

专项测试：`scripts/test-r4-backup.mjs`，**13/13 通过**。覆盖 localStorage、IndexedDB、secrets、cache、manifest、corrupt/unknown version、merge、duplicate、account isolation、partial failure、custom PDF、vocabulary、reading、cloze、Planner、AI records。
