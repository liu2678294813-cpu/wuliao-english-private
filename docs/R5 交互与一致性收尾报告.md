## 3. 精读工具栏

### 原因
collapsed 只隐藏子按钮，工具栏容器仍保留固定 `--reader-toolbar-height` 全宽占位，正文上方留下整条空白行。

### 实现
- `.annotation-toolbar.collapsed`：`height: 0 !important; min-height: 0 !important; padding/border/背景/阴影全部归零`，仅保留 `overflow: visible`。
- 展开入口改为紧凑悬浮 pill：`position: absolute`（锚定零高度 sticky 容器）、`min-height: 44px`、圆角胶囊、仅 118px 宽，不再占正常文档流高度。
- 折叠态 stage 提示：`<span class="toolbar-stage-hint">逐段精读 · 第 5/7 阶段</span>`（精读）/ `stage`（原 PDF）。
- collapsed 与 `topAreaCollapsed` 统一为**受控单一事实源**：`collapsed={topAreaCollapsed}`，review 卸载/重挂载后状态一致。

### collapsed 几何
- Custom Reader：折叠后 toolbar 文档流高度 0；`deep-reader-content` 补偿从 `-42px/22px` 变为 `2px`；正文有效阅读区域净上移约 62px。
- 原 PDF：`reader-main` padding-top 折叠态 46px（为悬浮 pill 保留不遮挡通道，仍比展开态 15px 明显上移 11px + toolbar 51px 释放）。
- 移动端（≤760px）：content 预留 46px 通道避免 pill 遮挡首行。
- scroll-margin 在折叠态收紧到 64px，跳转不再留大空白。

### anchor 处理
保留既有 `changeTopAreaCollapsed` 的几何补偿（测量 content 视口 top → rAF → `scrollBy` 保持当前阅读位置）。真机实测：折叠/展开前后正文顶部 y 仅相差 2px（311 → 313），无跳页。

### ink contract 保护
未改动：920px 文档宽度契约、Canvas 几何、perfect-freehand 数据、stroke schema、坐标归一化、tile 层、viewport preview 层。

## 5. 陌生词

### sourceType 兼容
- 复用 `wuliao-english / unknown-words` IndexedDB，`toggleUnknownWord` 主键语义不变。
- 新记录附加 `sourceType: "cloze" | "reading"`、`clozeId`、`sourceLabel`；旧记录缺省按 `reading` 处理。
- **无 IndexedDB 升级、无迁移、无批量 rewrite**：`openDatabase(DB_VERSION=3)` 原样；备份系统自动携带新字段（不升 backup version）。

### 阶段隔离（硬要求）
| 阶段 | 行为 |
|---|---|
| 导读 / 限时初做 / 自主复查 | 无陌生词入口（按钮不渲染） |
| 统一订正 | 可标记；只保存词，不查离线释义、不调用 AI、不弹中文输入框 |
| 逐空精析 / 全文回读 | 完整开放：标记/取消/离线释义/AI fallback（带 `aliveRef` mounted guard，StrictMode 修复）/人工补充 |
| D+1 / D+7 复习会话 | 整次复习期间无陌生词入口（提交前绝无词义泄露路径） |

### correction / analysis / final-read 行为
- correction：`lookUpMeaning: false`（契约测试断言）。
- analysis/final-read：离线词库 → DeepSeek（复用 `lookupWordMeaningWithAi`，不新增 prompt）→ 人工补充；组件卸载后不再写 IndexedDB。
- 正文交互：渲染层英文 token 拆分（`splitClozeTextTokens`），不动 parser 数据 / sentence identity / blank number / fingerprint；Blank 与选项按钮不被误识别。
