# 单词进度与手写筛选修复交付

版本：1.0.69 / versionCode 75。项目：`D:\codex库\无聊英语`。

## 最终行为

- 同账号、同词库、同单词共用计数、临时遮挡和最终完成状态。默认点击前两次分别显示 1/3、2/3，第三次锁定；默认有效右滑一次完成。循环遮挡计数、揭开不计数、第三次遮挡锁定。
- 切换规则或输入方式不重置状态。继承循环临时黑线后，默认点击保留黑线并继续计数。撤销、清除、刷新恢复和完成统计读取统一状态。
- 旧分模式记录任一完成即合并完成，否则保留循环进度；旧点击记录保留原计数。明确清除的统一状态优先于旧缓存。转换不会凭空新增今日完成记录。
- 筛选采用作文的平板工具栏和手写引擎，支持颜色、粗细、普通橡皮、自由套索、撤销、清空当前词；约 620 毫秒长按进入临时圈删，抬笔恢复。手指滚动不修改答案版本。
- “识别”处理整轮新增或修改的答案，包括屏幕外单词，依次保存笔迹、生成图片、转录、语义判断和归类。不确定保留待复核；重试不重复处理已完成答案；旧异步结果不能覆盖新答案。
- “对照”无需 AI，显示已有手写内容的词的词库标准汉语；空白词不显示。手写原迹仍保留，用户可自行正确／错误归类。键盘答案可直接进行 AI 判断。
- 删除底部批次导航和发音来源整行。按原词序连续滚动，采用可视区域加缓冲区渲染；活动行及待保存行保持挂载，笔迹和位置可恢复，旧批次位置转换为单词位置。

## 核实出的原因与修复

1. 默认与循环原先各自保存进度，默认点击又被改为一次完成；改为统一状态，并恢复三次点击规则。
2. 筛选虽然使用作文画布，但工具栏样式及活动行工具接口没有完整接入。复用同一工具栏与临时套索实现，仅真实笔迹变化增加版本。
3. 旧 Android 视觉密钥存在于作文原生存储，但新凭据读取只兼容旧明文位置；增加同账号、同端点的原生迁移及读回校验，保留回退副本。明确清除密钥时也清除对应旧副本，避免重新复活。
4. AI 设置的文本／视觉标签复用了同一个 React 实例，切到视觉后仍可能保存文本表单。现在按账号与类型重新挂载表单，并验证两类配置独立保存。用户此次为视觉输入的密钥被旧界面误存到文本配置，已按用户原意补存到同一接口的视觉配置。
5. 平板既有笔迹中，普通橡皮及部分越界笔画缺少新坐标标记。生成图片时兼容原归一化坐标与画布裁剪，保留橡皮擦除效果；损坏的新格式笔画仍明确报错。
6. 初始布局测量会卸载部分缓冲行，尚在队列中的挂载操作可能稍后返回已销毁错误。已卸载画布不再把这种过期错误写回当前页面提示。

长按问题未凭推测归因为模型或数据丢失。已验证共享引擎及筛选接入的模拟笔事件：长按圈删、抬笔续写、撤销均通过。没有把自动化模拟事件表述为人工持笔验收。

## 三个可直接复验的例子

1. 新词默认点击两次应显示 2/3 且仍可见；第三次遮黑，切循环或重进仍锁定。循环第一次遮黑后切回默认，应仍遮黑且仅计 1/3。
2. 给两个词写字，长按圈掉其中一笔，抬笔继续写，再撤销；滚动超过原第 20 词边界后返回，应恢复原笔迹和工具状态。
3. 只给第 1、35、80 个词写字：对照仅展示这三个词的标准汉语；识别覆盖屏幕外答案，正确／错误归类，不确定待复核，重复点击不重复归类。
