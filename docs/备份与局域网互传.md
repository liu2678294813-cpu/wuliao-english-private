# 备份与免费设备互传（1.0.100 / 106）

安卓、华为平板与 Windows 下载版可在同一 Wi-Fi 或热点内手动互传。学习数据不经过 GitHub 或付费服务器。两端都更新后，在相同名字的本机账号下操作。

1. 接收端：设置 → 数据备份与设备互传 → 接收其他设备数据。
2. 复制接收端完整 WL1 连接码，粘贴到发送端，点击发送。
3. 接收端确认账号与设备，然后确认接收。
4. 文件完整校验后查看差异：新增补入，相同跳过，冲突默认保留本机；需要时明确选择采用导入版本。
5. 点击确认导入，等待逐条写入校验完成。发送完成本身不会写入接收端的学习数据库。

连接码包含一次性 AES-GCM 密钥，只交给自己的设备；不记录到日志、URL 或数据库。等待配对最多 10 分钟，页面关闭后接收服务停止。第一版断网后重新发送，不含后台同步、异地中转或删除传播。

冲突按关联组选择，避免词库、导入资料、附件及答案分离。保留本机整组时，该组新增记录也暂不补入。界面只展示每组前 3 条摘要，选择会作用于整组；没有可靠更新时间时显示时间未知。笔迹按整份记录选择，不自动拼接。

替换前保存并回读恢复资料。导入历史可恢复被替换的原版本，新增记录继续保留；导入后继续学习的记录会跳过，以保护后来的操作。恢复资料单独存放，只有明确删除相应导入历史时才清理。

Windows 请完整解压，关闭旧版服务后双击启动文件，继续使用原浏览器和 `http://127.0.0.1:4173`。若仍显示旧页面，刷新；若服务检测到旧进程仍在运行，先关闭旧服务再启动新版。防火墙仅需允许新版运行环境在专用网络内通信，无需路由器端口映射。

连接失败时检查同一网络、所选网卡地址、Windows 防火墙和热点客户端隔离。备用方式：导出 JSON → USB 或 LocalSend 传文件 → 另一设备选择备份文件。导入始终先校验、再预览和确认。

此版本修复手动导出读取 Integer 分块位置时被 `PluginCall.getLong` 误判的问题。暂存改为分批事务；Android 导出成功要求目标文件回读大小和 SHA-256 一致。旧 v1 JSON 备份继续兼容，不包含密码、API Key 或可重建缓存。

升级安卓时直接覆盖安装，保留原包名、签名和 `https://localhost` 存储来源；不要卸载或清除数据。此轮没有安装生产平板，真实账号升级和实体设备 Wi-Fi 互传仍需单独验收。
