## 实现与数据映射

首页“资料导入”是三个资料库的新资料入口；批次固定单一目标。导入控制器负责真实队列、草稿恢复与账号会话校验；提取器负责完整页 PDF、必要页离线英文/中文 OCR、TXT/Markdown 编码及行号、DOCX 本地图文表格和 JSON 契约。结构解析器按文章/套题分别适配，审核前不向正式库写入。

| 存储 | 用途 | 正式备份 |
|---|---|---|
| 原 custom-pdfs | 精读或完形单条目标资料，兼容旧记录和 ID | 是 |
| 原 WritingRepository 和学习逻辑 key | W1–W8 冻结快照与学习事实 | 是，沿用原机制 |
| import-files | 账号+指纹共享原文件与本地题图 | 是，二进制附件 |
| import-batches / import-cache | 未提交草稿、提取及目标结构缓存 | 否，可重建 |
| writing-materials | 完整或待完善的自定义作文资料 | 是 |
| material-answers | 明确/待核对答案、来源及不可变版本 | 是 |
| material-explanations | 独立解析及其来源、版本 | 是 |
| answer-evaluations | 本地评分历史、原作答、当时答案记录和依据 | 是 |
| import-receipts | 提交恢复凭据 | 是 |

IndexedDB 8→9 保留全部旧 store。每条资料、答案、解析及回执在一个事务中写入，完成后回读。原文件复用，资料/题目身份不随标题或答案变化。正文有效但映射不明可保存；待核对记录不批改、不交给 AI 当缺失题。正式正确率只读取已核验内置官方身份，普通原文件、AI 和手动答案均按参考依据单独评分；无依据题不计分母，覆盖率另示。

答案订正、撤销和补充追加评分历史；解析单独订正不重评。重评从原学习事实读取作答，不重跑 AI、不修改计时、笔迹或已完成复习。启动、回到前台及答案变更后逐条扫描，依据稳定评分 ID 继续中断任务，不重复记账。资料保存后再生成的 AI 答案同样保留编辑前候选和正式版本；原文件答案被人工改值后，新版本标为 manual，原始 source_document 版本保留。恢复检查来源、图片、答案及材料引用，冲突保留本地数据并报告。

## AI 边界

默认路径零 AI 请求。用户主动选择后先展示待发送题目和必要上下文，再确认调用现有 Text AI Provider；按文章/完形合并请求，只补真正缺失题。候选经过题目身份、选项和 Schema 校验，用户可编辑、删除或主动重生成，正式保存前需确认。已确认原文件答案禁止静默覆盖；AI 来源始终 `ai_generated`，被编辑的原候选及后续版本保留。参考答案的 AI 解释单独确认并生成待审核解析，不自行改判。无配置、失败、取消或账号切换不妨碍有效原资料保存。

全部自动化 AI 验证采用受控响应，为模拟测试。本任务未向真实 Provider 发起付费验收调用。

## 已知限制及续验步骤

首次自动解析采用显式章节/题号和现有本地规则；无明确边界的复杂排版可能需要人工结构编辑。中文 OCR 是本地识别，其准确度需对照原件核对。首版选择题契约为 A–D，非 20 空允许，正文空位必须与选项一一对应。结构 AI 仅给原文边界建议，结果不自动替换资料。

从最新远端隔离构建时发现并修复两个可复现的问题：词汇包补丁以包含 LF 的整行判断是否已打补丁，Windows CRLF 检出会重复插入 import；现在判断声明本身，并用 LF/CRLF 两种输入验证幂等性。官方作文题库测试此前依赖未入库的 scripts/output 审计文件；现在随源码保存仅含覆盖元数据的测试 fixture，继续验证全部官方题目身份、指纹、题图和冻结快照，不上传来源 PDF、目录扫描清单或私人资料。

仓库内的合成文件可复现解析测试；用户真实、多卷、特殊排版资料尚未抽样验收。没有把所有 217 个浏览器用例重新执行；实际执行的是与此次变更相关的流程，其他单元回归已运行。设备存储空间不足以事务中止验证失败回滚，未在平板上实际填满存储。

平板恢复连接后，先检查设备版本和 APK 证书，并保证拟安装版本高于执行时源码/设备最高版本；停止应用后备份私有数据、保存全部文件 SHA-256 和旧包信息。仅使用兼容签名的 `adb install -r -d`，安装后先比对数据再启动，核对版本、前台 MainActivity、PID 和原学习记录。随后用隔离账号验收多文件选择、原生离线 OCR、系统返回、后台回收、横竖屏和手指/笔操作。签名、备份或数据保全条件不满足时停止安装。

资料只有能从目标资料库打开、写入训练并重启恢复才计为导入验收通过；当前这一标准已在浏览器隔离账号验证。平板的同项标准仍待实测。
