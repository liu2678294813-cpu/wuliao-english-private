# 覆盖更新与空间清理

设置 → 关于 → 检查更新。确认更新后下载、校验并备份全部账号学习数据，再交给 Android 系统更新现有应用。首次修复旧更新器时，直接打开新版 APK 覆盖安装；不要卸载旧版或清除数据。

- 包名保持 `com.wuliao.english`，继续使用既有签名证书和 `https://localhost` 存储来源。
- 原生安装使用 PackageInstaller Session；目标版本、任务编号及结果持久保存。下载完成或提交安装不算更新成功，实际安装版本达到目标才显示完成。
- 设置页在重启、恢复前台时读取原生状态，等待确认时提供继续安装或取消更新。
- 更新 APK 和残片仅保存在更新专用临时目录，成功、取消或失败后清理；启动时补做遗留清理，正在安装的文件不会提前删除。
- 长期仅保留最近一份完整、已校验的全账号更新备份。生成新备份时保留旧备份，新备份全部校验成功后才淘汰旧备份。
- 更新备份按分块读取导入附件、计算校验和并写入标准 Backup v1 JSON，避免在 WebView 中同时展开多份完整附件和备份；原生文件回读校验通过后才允许安装。
- 删除范围仅限更新器自己的临时文件、安装任务与历史更新备份。学习数据库、笔迹、用户导入材料和用户手动导出的文件不在清理范围。
- 下载和安装期间需要临时空间。结束后保留已安装应用、正常学习数据和最近一份安全备份；更新包与旧备份不按更新次数累计。

所有安装前保存、读取和备份校验失败都会停止安装。没有自动旧备份恢复、数据库重建或学习数据初始化。

验证覆盖控制器、全账号备份、原生文件清理、实际版本判断及进程恢复。隔离真机连续升级三次后，临时 APK 为零、完整备份保持一份、两个测试账号的进度和笔迹一致；另验证网络中断、损坏包和取消下载。正式设备更新前另做私有文件备份，更新后对比全部账号持久化记录和重启后的显示状态。
