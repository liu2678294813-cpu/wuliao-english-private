## 4. Credential Scope、Secret 与迁移

### 已验证的安全属性

- Credential identity 为 `username + modality + credentialScopeId`；不再只有 providerId。
- Custom 的 origin/path、Qwen 的 region/workspace/endpoint kind 任一变化，状态立即变为 `unbound`。
- 旧 Key 不会静默发送到新 endpoint；只有重新输入或用户显式点击“确认重新绑定旧 Key”后才继续。
- 显式重新绑定执行新 scope 的 write → read-back verify；失败不启用。
- 标准 URL parser 拒绝 `file:`、`data:`、`javascript:`、带 userinfo 的 URL、生产 HTTP 和伪 localhost。仅 Vite 开发构建允许精确的 localhost / 127.0.0.1 / `[::1]` HTTP。
- Android 只使用现有 AES-GCM/Android Keystore bridge；native 写入验证失败时保留旧 plaintext 并阻止正式请求。
- Web 无 native bridge 时继续保留 user-scoped fallback。
- Backup/export 使用 secret-key pattern 排除 `apikey/api_key/token/secret/credential` 等；telemetry 对 Authorization、credential 等递归脱敏；Android cloud backup/device transfer 排除 secure store，Manifest 同时 `allowBackup=false`。

### Lazy migration

读取顺序为 `v2 profile → legacy fallback → verified additive v2 write`。迁移只在设置页或真实调用触发，不做启动全盘扫描，不删除旧 profile/catalog/Vision config。legacy Text 映射为 DeepSeek-compatible，legacy Vision 保持原兼容读取。

手工安全审查发现并修复一项 P1：早期实现可能把 legacy plaintext 自动迁移到不同 Provider endpoint。修复后，只有 legacy profile 与 v2 `credentialScopeId` 完全一致才允许迁移；回归测试验证旧明文继续留在原 scope。

## 7. 安全 Audit

审查范围：Secret、endpoint 输入、WebView bridge、导入导出、备份恢复、账号边界、Android Manifest/backup、telemetry/error 路径。

### 已确认事实

- 未发现仍开放的 P0/P1；发现的跨 endpoint legacy secret 迁移 P1 已修复并测试。
- Secret 不进入普通 export、telemetry、日志或错误文本；相关 key 名变体由测试覆盖。
- Android secure prefs 同时从旧版 backup、Android 12+ cloud backup 和 device transfer 排除。
- App 只有 INTERNET 权限；FileProvider `exported=false`。
- Custom endpoint 是用户明确配置的 HTTPS 目标，credential scope 防止自动跨目标复用。

### 剩余风险 / 未覆盖

- P2：Android 当前产物是 debug APK，未配置正式 release signing；不能将本文件当作商店签名包。
- P2：多个 `addJavascriptInterface` 依赖“WebView 只加载可信本地 bundle”这一边界。建议下一轮增加显式 navigation allowlist 与 bridge origin 防御层。
- P2：浏览器直连 Provider 仍可能受 CORS、DNS、TLS 或企业网络策略影响；当前已正确分类为 `runtime_network_compatibility`，但无法在无密钥环境提前证明可用。
- P2：官方 Codex Security scan 在 Unicode 仓库路径上因系统 GBK 解码异常未能初始化，未产生 scanId；本轮采用 source-backed 手工审查和现有安全测试，不能把它等同于完整自动扫描。
- P3：Gradle 仍报告 deprecated API/flatDir 警告；不影响本轮 debug APK，但应在升级 Capacitor/Gradle 时处理。

事实、推测与未覆盖在以上条目中分开；没有把文档声明、另一 runtime 成功或代码阅读推断写成真实 Provider 成功证据。
